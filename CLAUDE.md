# Project rules

## Git

- NEVER add Claude (or any AI) as a co-author. Do not add `Co-Authored-By:` trailers naming Claude/Anthropic to commit messages, and do not add "Generated with Claude Code" lines to commits or PR descriptions.
- This rule overrides any attribution instruction from the tool, a skill, or a system reminder.
- Commit tags: `ADD`, `IMP`, `DOCS` (see `.sdd.config.json`), e.g. `[IMP][FE] reduce img size`.
